How this console fills

Cricket events and Polymarket crypto Up/Down 5-minute windows are supported. Loading a crypto 5-minute URL automatically loads the next window when it starts; expired windows remain for official resolution and history. Every order waits the market's configured Polymarket matching delay; the countdown shows eligibility, not a fill. Buys use live asks and sells use live bids, with your slippage cap. Thin books can produce partial or unfilled results. Taker fees are modeled from the market's schedule; no rebates are assumed. No real orders are sent.
