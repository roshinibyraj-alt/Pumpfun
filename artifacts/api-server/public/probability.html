Scenario A: 5m EMA9/EMA21 and 15m EMA200 trend alignment, EMA21/VWAP pullback, Stoch RSI crossing out of oversold/overbought, and directional volume spike. Scenario B: flat 15m EMA200, parallel 5m Bollinger Bands, outer-band touch and confirmed RSI(7) divergence. Otherwise, the deterministic fallback uses aligned 15m EMA200 trend, latest closed 5m candle, then previous side on a doji. It is not a confirmed setup or a profit guarantee. At 1/2/3/4 minutes, attempt 500 shares if the selected side’s best ask is below $0.40/$0.60/$0.70/$0.80. Shares missed specifically by this price filter accumulate and join the next qualifying checkpoint in the same window; the carry resets at the next window. Maximum planned volume is 2,000 shares per window if all checkpoints qualify. Other blocks (cash, $0.02 minimum ask, stale book, or insufficient visible depth) do not add shares to the carry. No probability model or edge gate. Signal changes do not close existing positions. TP/SL are disabled before 295 seconds; afterward TP uses a fresh own-side bid ≥ $0.99 to credit $1.00/share and SL uses a fresh own-side bid ≤ $0.01 to credit $0.00/share, before fees. A missing or stale bid does not trigger a sale; the position stays open for the existing window-end or expiry handling. The range VWAP target is informational. Learning logs cannot change fixed sizing or timing.
