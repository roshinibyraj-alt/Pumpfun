Net edge = model probability − outcome ask − estimated fee. A 5¢ upward crossing triggers one paper buy; it rearms after the edge falls below 5¢.

Simulation only—no live order submission. Probabilities use a normal-CDF approximation from the previous 20 completed Binance BTC 5-minute candles. Position exits use the fresh own-side CLOB best bid: $0.99 credits $1.00 gross per share, and $0.01 credits $0.00 gross. The configured Polymarket taker-fee formula is applied to entries and exits. Any still-open position at window close is marked at its last own-side bid; BTC reference prices do not decide paper P&L.
