Strategy rulesSignal · entries · exits

The latest closed 5-minute candle selects the side: green → UP, red → DOWN. A doji after 2 or more consecutive green candles selects DOWN; a doji after 2 or more consecutive red candles selects UP. A doji without either run does not create a new side.

From seconds 1–60, 61–120, 121–180, and 181–240, the bot checks every 500 ms and buys 500 shares immediately when the selected side’s fresh best ask first falls below that stage’s $0.40, $0.60, $0.70, or $0.80 cap. If a stage ends without meeting its cap, its 500 shares carry forward to the next qualifying stage in the same window. Maximum planned volume remains 2,000 shares per window. Paper cash, the $0.02 minimum ask, fresh quotes, and visible depth checks still apply.

TP/SL are disabled before 295 seconds. After that, TP uses a fresh own-side bid ≥ $0.99 to credit $1.00 per share; SL uses a fresh own-side bid ≤ $0.01 to credit $0.00 per share, before fees. A missing or stale bid does not trigger a sale; the position stays open for expiry handling. Signal changes do not close existing positions, and learning logs do not change the fixed execution settings.

Paper only—no live orders. Closed 5-minute candles choose the side; the existing schedule, sizing, entry checks, exits, and account handling remain in place.
